# Right-click menu (P1)

Right-clicking in the document shows the app's own context menu instead of the
browser's (styled as a menu, see 09, 260px wide, with icons in the icon
column). Position: at the pointer, flipped to stay inside the window. With
the Shift key held, the browser's menu is shown instead (so spell-check
suggestions stay reachable).

Contents (disabled items as noted):

- Cut ⌘X (disabled without a selection)
- Copy ⌘C (disabled without a selection)
- Copy as Markdown (disabled without a selection)
- Paste ⌘V
- Paste without formatting ⌘+Shift+V
- Paste from Markdown
- Delete (disabled without a selection)
- —
- Comment ⌘+Option+M (disabled without a selection)
- —
- Insert link ⌘K
- —
- Format options ▸ — Text ▸ (as Format > Text), Paragraph styles ▸, Align
  and indent ▸, Line & paragraph spacing ▸
- Clear formatting ⌘\

Inside a table, the table items from 11 are inserted after the first group.
On a link, add "Copy link" and "Remove link" after Insert link (labelled "Edit
link" instead of "Insert link").

Right-clicking does not move a non-empty selection if the pointer is inside
it; otherwise it places the cursor at the pointer first.

## Acceptance

- Right-click shows the menu with the items above; Cut/Copy/Delete are
  disabled without a selection.
- Shift+right-click shows the browser menu.
- Inside a table the table items appear.
